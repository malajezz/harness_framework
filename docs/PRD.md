# PRD: TubeNext

## 목표
유튜브 채널을 분석해 "지금 어떤 컨텐츠를 하고 있는지" 파악하고, 같은 분야에서 viral·hot한 영상을 찾아 "다음에 만들면 좋을 컨텐츠"를 근거와 함께 추천한다.

## 사용자
다음 영상 주제를 고민하는 1인 유튜브 크리에이터 / 채널 운영자.

## 핵심 기능
1. **채널 분석** — 채널 핸들(@handle) 또는 채널 URL을 입력하면 최근 영상과 통계를 수집해, Claude가 채널의 컨텐츠 정체성·주제·톤을 요약한다.
2. **Viral 탐색** — 분석된 주제 키워드로 유사 영상을 검색하고, **일평균 조회수**(viewCount ÷ 업로드 후 경과일) 기준으로 hot한 영상을 선별해 보여준다.
3. **차기 컨텐츠 추천** — 채널 정체성 + viral 트렌드를 결합해 Claude가 다음 컨텐츠 3~5개를 **제목 + 추천 근거**(+참고 영상)와 함께 제안한다.

## MVP 제외 사항
- 로그인/인증, 사용자 계정
- 데이터베이스/저장/히스토리 (요청 시 실시간 조회만, stateless)
- 결제/과금, 사용량 제한 UI
- 다국어, 다크/라이트 토글 (다크 고정)
- 영상 자동 생성/대본 작성

## 디자인
- 다크모드 고정, 미니멀한 "도구" 느낌의 대시보드 (마케팅 페이지 아님)
- 무채색 기반 + 포인트 색상 1가지
